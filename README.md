# hal_stm32

[![Version](https://img.shields.io/github/v/release/LuckkMaker/hal_stm32)](https://github.com/LuckkMaker/hal_stm32/releases/latest)


## 介绍

**hal_stm32** 是 [omni-emb](https://github.com/LuckkMaker/omni-emb) 的一个组件库。 它基于 [STM32CubeF4](https://github.com/STMicroelectronics/STM32CubeF4) 项目，增加 omni module 文件，使其能够与 omni-emb 一起使用。

[omni-emb](https://github.com/LuckkMaker/omni-emb) 项目是一个嵌入式开发平台，同时提供 HAL 层驱动和各种组件驱动。可以根据不同板卡、不同模块的需求，自由选择需要的组件，构建自己的固件。
可以从 [releases page](https://github.com/LuckkMaker/omni-emb/releases) 获取最新的 omni-emb 版本。
